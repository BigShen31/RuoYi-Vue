# 01 · 需求说明 —— 招商项目库（OPC 机试演示基线）

> 所属套件：OPC 机试 30 分钟交付套件（RuoYi-Vue3 前端 + RuoYi-Vue 后端，前后端分离）
> 配套设计文档：`02-设计.md`；测试：`03-测试.md`；交付：`04-交付.md`；实战手册：`05-实战手册.md`

## 1. 场景背景

招商主管部门需要一套「招商项目库」台账：登记来访/洽谈的招商项目，记录项目从**洽谈 → 签约 → 落地**的推进过程，供领导和招商人员随时掌握项目总量、在谈数量与落地情况，支撑招商进度汇报。

本项目在若依（RuoYi）前后端分离框架之上，以该场景为默认演示基线，验证：登录鉴权、列表分页搜索、完整 CRUD、状态流转、统计卡片、菜单与按钮权限。

## 2. 澄清问题与默认答案

现场拿到任意场景时，使用以下问题模板向业务方/评审澄清；基线场景的预设答案如下（机试默认按预设答案执行，无需再次询问）。

| # | 澄清问题 | 基线答案（招商项目库） |
| --- | --- | --- |
| 1 | 使用方与核心诉求 | 招商部门内部台账，领导看统计、招商员录项目 |
| 2 | 一条记录的“主对象”是什么 | 招商项目（企业拟落地项目） |
| 3 | 状态有哪些、是否单向推进 | 洽谈中→已签约→已落地，单向逐级推进 |
| 4 | 签约/落地是否有业务日期 | 有；推进到“已签约/已落地”时自动记录对应日期 |
| 5 | 金额口径与单位 | 计划投资额，单位：万元 |
| 6 | 是否需要删除 | 需要（逻辑删除：置 del_flag=2，列表不再显示，数据保留可恢复） |
| 7 | 列表需要哪些搜索条件 | 项目名称、项目编号、行业类型、项目状态 |
| 8 | 统计口径 | 项目总数、在谈、已签约、已落地（按状态计数） |
| 9 | 行业类型是否固定 | 预置字典：智能制造/新能源/生物医药/数字经济/现代服务/其他 |
| 10 | 权限粒度 | 菜单 + 按钮权限（list/query/add/edit/remove/status），admin 全量 |
| 11 | 账号体系 | 沿用若依内置 admin/admin123，演示权限页用系统管理原功能 |

## 3. 功能清单

| 功能 | 说明 | 验收点 |
| --- | --- | --- |
| 登录鉴权 | 若依 JWT + 验证码 + Redis | 登录成功进首页；未登录访问跳登录页 |
| 列表查询 | 分页 + 关键词（名称/编号）+ 精确（行业/状态） | 条件组合正确、分页正常 |
| 新增 | 表单校验（必填/长度/金额） | 保存后列表可见 |
| 编辑 | 回显 + 保存 | 字段更新生效 |
| 删除 | 支持多选批量删除 | 数据消失、提示成功 |
| 状态推进 | 洽谈中→已签约→已落地（逐级）；推进到签约/落地时自动写日期 | 非法跳级被拦截并提示 |
| 统计卡片 | 总数 / 在谈 / 已签约 / 已落地 | 与列表数据一致 |
| 字典 | 行业类型、项目状态走系统字典 | 下拉有值、无脏数据 |
| 权限演示 | 系统管理：用户/角色/菜单页面可浏览 | 页面无红屏 |

## 4. 验收标准

- [ ] MySQL 与 H2 两种模式均可启动，登录 + 列表 + CRUD + 搜索 + 统计全链路可演示
- [ ] 状态只能按 洽谈中→已签约→已落地 逐级推进，跳级/回退有明确提示
- [ ] 菜单与按钮权限由 `sys_menu` 控制，无权限按钮不渲染
- [ ] 前端页面无控制台报错；换场景流程 ≤ 5 分钟（实测记录见 05）

## 5. 数据字段清单（biz_project）

| 列名 | Java 属性 | 类型 | 约束 | 含义 | 查询方式 |
| --- | --- | --- | --- | --- | --- |
| project_id | projectId | bigint | PK 自增 | 主键 | - |
| project_name | projectName | varchar(100) | 非空 | 项目名称 | 模糊 |
| project_code | projectCode | varchar(50) | - | 项目编号 | 模糊 |

| invest_amount | investAmount | decimal(14,2) | 非负 | 计划投资额（万元） | - |
| project_status | projectStatus | varchar(10) | 非空，默认 0 | 状态（字典 biz_project_status） | 精确 |
| sign_date | signDate | date | - | 签约日期 | - |
| landed_date | landedDate | date | - | 落地日期 | - |
| contact_name | contactName | varchar(50) | - | 联系人 | - |
| owner | owner | varchar(50) | - | 招商负责人 | - |
| remark | remark | varchar(500) | - | 备注 | - |
| del_flag | delFlag | char(1) | 默认 0 | 删除标志(0存在 2删除) | - |
| create_by / create_time | createBy/createTime | - | 若依审计 | 创建人/时间 | - |

## 6. 接口清单

| # | 方法与路径 | 说明 | 权限标识 |
| --- | --- | --- | --- |
| 1 | GET /system/project/list | 分页条件查询 | system:project:list |
| 2 | GET /system/project/{id} | 详情 | system:project:query |
| 3 | POST /system/project | 新增 | system:project:add |
| 4 | PUT /system/project | 修改 | system:project:edit |
| 5 | DELETE /system/project/{ids} | 删除（可批量） | system:project:remove |
| 6 | PUT /system/project/status | 状态推进 | system:project:edit |
| 7 | GET /system/project/statistics | 统计（总数/在谈/签约/落地） | system:project:list |

统一响应结构：`{ code, msg, data }`，成功 code=200；分页结构遵循若依 `TableDataInfo`。
