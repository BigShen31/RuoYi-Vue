## 4. 演示讲解词（招商项目库示例，约 3 分钟）

1. **开场**：“这是一套基于若依前后端分离框架的招商项目管理系统，后端 Spring Boot + MyBatis，前端 Vue3 + Element Plus。”
2. **登录**：演示 JWT + Redis（说明验证码可开关是系统参数）。
3. **统计页**：四张卡——总数 10、在谈 3、已签约 4、已落地 3，数据来自数据库实时聚合，不是写死的。
4. **列表/搜索**：按“新能源”行业过滤，说明列表是分页 + 条件查询。
5. **状态流转**：新增一条洽谈中项目 → 点「签约」→ 系统自动记录签约日期 → 再点「落地」→ 自动记录落地日期；强调状态机在 Service 层校验，跳级/回退会被拦截（演示非法操作提示）。
6. **权限**：按钮权限由 sys_menu 控制（v-hasPermi + 后端 @PreAuthorize 双重校验）。
7. **收尾**：双数据库——日常 MySQL，应急一条命令切 H2 内存库；换新业务只改“场景 SQL + 模块模板 + 前端 scene 配置”三处。

## 5. 应急预案

| 故障 | 处置 |
| --- | --- |
| MySQL 起不来/密码不对 | 切 H2：`java -jar ruoyi-admin.jar --spring.profiles.active=h2` |
| Redis 没开 | 运行 `E:\Program Files(AI)\tools\redis\redis-server.exe --port 6379` |
| 页面 401/红屏 | F12 看 Network/Console；后端日志在启动窗口；多为菜单/权限未刷新 → 重新登录 |
| 端口被占 8080/80 | 改 application.yml 端口或 vite.config.js port，并同步代理目标 |
| 时间不够 | 保骨架（列表+新增）先演示，再补统计/状态机；讲解词用“该能力框架已具备”过渡 |
