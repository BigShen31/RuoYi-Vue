## 3. 接口自测记录（真实环境）

### 3.1 MySQL 模式（默认）

| 步骤 | 结果 |
| --- | --- |
| 登录 admin/admin123（验证码已按演示配置关闭） | code=200，返回 Token |
| GET /system/project/list | total=10，rows=10 |
| GET /system/project/statistics | `{total:10, signed:4, negotiating:3, landed:3}` |
| POST 新增（智慧园区） | code=200，projectId=11 |
| PUT /status 0→1→2 | 200；详情 signDate=landedDate=当天，自动落值 |
| PUT /status 回退（2→0） | code=500，提示“状态只能按…逐级推进” |
| PUT 编辑 | code=200 |
| DELETE /{id} | code=200，统计回落 total=10 |
| 未带 Token 访问 | code=401（权限链路生效） |

### 3.2 H2 内存模式（保底）

命令：`java -jar ruoyi-admin.jar --spring.profiles.active=h2`

启动 10.5s 自动建表灌数；登录/列表(total=6)/统计/新增/推进/删除全部 200；登录日志与操作日志异步写入无报错。

## 5. 已知测试边界

- 删除为物理删除（若依生成器默认）；如需逻辑删除可加 del_flag 列（列为优化项）。
- 单元测试未覆盖 Mapper SQL（联库自测已覆盖）；H2 仅覆盖核心 sys_* 表与业务表最小集。
