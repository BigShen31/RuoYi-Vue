## 3. 启动步骤

### 3.1 前置：Redis

```bat
E:\Program Files(AI)\tools\redis\redis-server.exe --port 6379 --logfile redis.log
```

### 3.2 模式一：MySQL（默认，演示主路径）

```bat
cd /d D:\iTwoLeg\OPC项目\RuoYi-Vue
java -jar ruoyi-admin\target\ruoyi-admin.jar
```

```bat
cd /d D:\iTwoLeg\OPC项目\RuoYi-Vue3
npm run dev
```

浏览器 http://localhost，账密 admin/admin123。

> 说明：本机演示已把 `sys_config.sys.account.captchaEnabled` 置为 false（免输验证码，提升演示顺畅度）。全新导入 ry 库后如需同样配置：
> `UPDATE sys_config SET config_value='false' WHERE config_key='sys.account.captchaEnabled';` 并重启后端。

### 3.3 模式二：H2 内存库（机试保底，一条命令）

```bat
cd /d D:\iTwoLeg\OPC项目\RuoYi-Vue
java -jar ruoyi-admin\target\ruoyi-admin.jar --spring.profiles.active=h2
```

应用启动时自动建表 + 灌入演示数据（登录 admin/admin123、场景数据 6 条、验证码默认关闭）。前端启动方式不变。

> 注意：H2 只替代数据库；登录/Token 仍需本机 Redis 处于运行状态。

## 4. 演示路径（推荐顺序）

1. 登录（讲解 JWT + 验证码开关策略）
2. 首页与系统管理概览（权限演示素材）
3. 招商管理 → 招商项目库：统计卡片 → 列表 → 搜索 → 新增 → 状态推进（签约/落地，日期自动落）→ 编辑/删除
4. 系统管理 → 用户/角色/菜单 走一圈（RBAC 说明）
5. 收尾：双模式一句话（MySQL 日常 / H2 保底），换场景三件套（详见 05）
